# Russian and Caucasus Studies (RCS)

Official website repository for **Russian and Caucasus Studies (RCS)**, an academic journal focused on Russian studies, Caucasus studies, language, linguistics, literature, culture, translation, and related interdisciplinary research.

## Website Structure

This repository contains the journal's multilingual static website infrastructure, including:

- Persian, Russian, and English interfaces
- Responsive navigation and dropdown menus
- Editorial board profile placeholders
- Author and article sections
- Issues and archive structure
- Author guidelines and submission resources
- Peer-review and publication policies
- Publication ethics and plagiarism policies
- Copyright and licensing pages
- Journal information and metrics
- Verification-system infrastructure
- Article templates and author forms

## Editorial Board

The editorial board page currently contains **empty profile boxes only**. Names, photographs, affiliations, academic ranks, ORCID identifiers, and other member information will be added after the editorial structure is finalized.

## Publication Languages

**Persian · Russian · English**

## Repository Policy

Confidential manuscripts, reviewer reports, personal data, and other non-public editorial materials should not be stored in this public repository.
